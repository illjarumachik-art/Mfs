# STEM Solar Robot — продающая карточка 16:9

Горизонтальная рекламная карточка для лендинга конструктора **STEM Solar Robot 12 в 1** с акцентом на работу от солнца без батареек.

## Файлы

| Файл | Назначение |
|------|------------|
| `assets/stem-solar-robot-landing-card-1920x1080.png` | Финальная карточка **1920×1080** |
| `assets/stem-solar-power-scene-bg-1920x1080.jpg` | Фотосцена (балкон, солнечные лучи, пловец в воде) |
| `landing/index.html` | Адаптивная веб-карточка |
| `landing/capture.html` | Экспортный кадр 1920×1080 |

## Превью

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765/landing/
```
