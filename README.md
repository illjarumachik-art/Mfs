# STEM Solar Robot — продающая карточка 16:9

Горизонтальная рекламная карточка для лендинга конструктора **STEM Solar Robot 12 в 1**.

## Файлы

| Файл | Назначение |
|------|------------|
| `assets/stem-solar-robot-landing-card-1920x1080.png` | Финальная карточка **1920×1080** (HTML + фотосцена, чёткий русский текст) |
| `assets/stem-solar-robot-landing-card-flat-1920x1080.jpg` | Цельный фотореалистичный рендер с запечённым текстом |
| `assets/stem-solar-robot-scene-bg-1920x1080.jpg` | Фотосцена без текста (для веб-оверлея) |
| `landing/index.html` | Адаптивная веб-карточка с типографикой и CTA |
| `landing/capture.html` | Экспортный кадр ровно 1920×1080 |

## Превью

Из корня репозитория:

```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/landing/
```
